# HR-Employee-Attrition-Analysis
#  HR Employee Attrition & Retention Dashboard

##  Project Overview
This project presents an interactive **HR Analytics Dashboard** built using Power BI and Microsoft Excel. The goal of this analysis is to evaluate employee turnover trends, identify key factors contributing to workforce attrition, and provide actionable insights for HR leadership to improve employee retention strategies.

## Key Metrics (KPIs)
* **Total Employees:** 1,470
* **Attrition Count:** 237
* **Attrition Rate:** 16.12%
* **Average Monthly Income:** $6,503
* **Average Age:** 36.9 Years
##  Key Business Insights
* **Departmental Impact:** Sales and R&D departments show distinct attrition trends, requiring targeted retention plans.
* **Overtime vs. Attrition:** Employees working overtime exhibit significantly higher attrition rates compared to non-overtime employees.
* **Compensation & Satisfaction:** Lower monthly income coupled with lower job involvement strongly correlates with employee turnover.
##  Tools & Technologies Used
* **Power BI** (DAX Measures, Data Modeling, Custom Canvas Layout, Interactive Slicers)
* **Microsoft Excel** (Data Cleaning & Exploration)
